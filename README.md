# Wordle Solver

## 🚀 Live Demo

[**Try Wordle Solver**](https://ibrahimnaoun.github.io/Wordle_solver/)

A lightweight, offline Wordle solver built with HTML, CSS, and JavaScript.

Enter your guesses, mark each letter as green, yellow, or gray, and find words that match your clues.


## Features

- Supports up to five guesses.
- Filters words based on letter positions and exclusions.
- Handles duplicate letters using Wordle-style letter counts.
- Supports custom word lists.
- Copy results or export them as a `.txt` file.
- No AI, APIs, or data sharing.

## Usage

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Load a word list or use the built-in test list.
4. Enter your guesses and mark the tiles according to Wordle's feedback.
5. Click **Find matching words**.

For automatic dictionary loading, place `five_letter_words.txt` in the same directory as `index.html`.
